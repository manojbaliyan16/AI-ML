# AI-ML

Learning notes and exercises for AI/ML, starting with Python and NumPy.

## Layout

- `python/` - lists, dictionaries, exception handling, file handling, CSV, JSON
- `numpy/` - fundamentals, intermediate, advanced
- `pandas_eda/` - Pandas and exploratory data analysis, novice to advanced (see `CHECKLIST.md` inside)
- `Module_1_NP_PD/` - course material for NumPy and Pandas: `notebooks/` (class and practice notebooks), `data/` (datasets, not committed), `docs/` (pre-reads)

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
